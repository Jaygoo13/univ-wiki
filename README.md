# UnivWiki (대학 입시요강 분석)

대학 모집요강·대입전형 시행계획 원문을 바탕으로 정리한 입시 분석 페이지 모음입니다.

## 페이지 목록

모든 페이지는 휴대폰에서 좌우 스크롤 없이 한 화면 폭으로 보입니다(좁은 화면에서는 표가 카드로 바뀝니다).

### 👉 [2026 입시결과 검색 (result-2026.html)](https://jaygoo13.github.io/univ-wiki/result-2026.html)
- 대학·학과를 한 줄로 검색하면 전형별 등급컷·백분위 컷·경쟁률·충원을 카드로 보여 줌 (예: 경희대 경영 수시)
- 42개 대학의 2026학년도 입시결과(진학사 입시결과 자료실) 원문 값 그대로, 지표 이름과 근거 쪽 표시
- 대학 별칭·학과 줄임말 인식, 수시/정시·전형 유형 필터, 대학별 보기, 검색 주소 공유

### 👉 [2027 수도권 대학 정시 전형 (jungsi-2027.html)](https://jaygoo13.github.io/univ-wiki/jungsi-2027.html)
- 수도권 38개 대학 정시 수능위주 일반전형(정원 내)의 이공계와 문과 계열을 한 페이지에 정리 (이전 이공계·문과 페이지를 합침)
- 계열 단추(전체·이공계·문과), 대학 이름으로 거르기, 학교별 요약 카드(포함 인원·경계 사례·제외 단위·판독 불확실 항목)
- 대학별 수능 반영비율·가산점·영어·한국사·학생부, 가·나·다군별 계열 묶음 모집인원, 대학별 인원 합계
- 휴대폰에서는 자동으로 카드 보기, PC에서는 표 보기 선택 가능, 모집요강 원문 페이지 근거 명시
